## Reporting a Vulnerability
Do not use github as the means to disclose to me vulnerabilities you find.

Do not use any vulnerabilities you haven't disclosed to me.

Do not expect me to fix issues that would ordinarily only apply to high value entities. Or things only an LLM has found.

I can be found on mastodon. Youtube is not the appropriate channel to contact me about issues, or any other public venue.
